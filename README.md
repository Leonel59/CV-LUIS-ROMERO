## Ver
- Abre `CV-LUIS-ROMERO.html` en el navegador, o
- Abre `index.html` (misma copia, lista para GitHub Pages).

## Publicar con GitHub Pages
1. Ve a Settings → Pages.
2. Source: Deploy from a branch → Branch: `main` / `/ (root)`.
3. Guarda y abre la URL que te da GitHub.
